# Unauthorized Access Response (Prototype Demonstration Material)

For unexpected access to a system, repository, storage location, or administrative function, preserve audit logs and validate the identity, permission path, source device, source network, and actions performed. Determine whether access resulted from a compromised account, excessive permission, exposed service, token theft, or configuration error.

Contain by revoking sessions, disabling abused credentials, correcting access controls, and restricting the exposed path. Preserve before-and-after permission state. Search for persistence, privilege escalation, changes, exports, and access to other assets. Rotate affected secrets, validate least privilege, restore unauthorized changes, and monitor.

Hungarian retrieval aliases: jogosulatlan hozzáférés, ismeretlen felhasználó, engedélymódosítás, illetéktelen belépés, külső fiók, hozzáférési napló.

Increase severity for successful access, privilege escalation, persistence, sensitive repositories, destructive changes, exports, or access to multiple assets. Preserve repository audit logs, commit and permission history, access tokens, SSH keys, source IPs, user agents, and affected-object lists. Validate restored permissions against an approved baseline rather than memory.
